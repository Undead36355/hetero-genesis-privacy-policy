# Hetero-Genesis Privacy Policy

Static privacy policy page for `Hetero-Genesis` / `异构进化`.

Recommended GitHub Pages URL after enabling Pages for this repository:

```text
https://undead36355.github.io/hetero-genesis-privacy-policy/
```

## Publish

1. Push this repository to GitHub.
2. In GitHub, open Settings -> Pages.
3. Set Source to `Deploy from a branch`.
4. Select branch `main` or `master`, folder `/ (root)`.
5. Use the GitHub Pages URL in Google Play Console and App Store Connect.

## Release Check

This policy assumes the final build remains a local single-player game with no account, ads, IAP, analytics SDK, telemetry SDK, cloud save, or network data collection. Re-scan the final build before store submission.
